      About

      CropGuard AI identifies crop diseases from a single leaf photo and provides treatment recommendations based on live weather conditions.

      —
      rice accuracy
      —
      wheat accuracy

      Crops

      • Rice — Bacterial Blight, Blast, Brown Spot, Tungro
      • Wheat — Crown & Root Rot, Leaf Rust, Loose Smut

      Pipeline

      1. Upload single leaf photo
      2. Crop classifier (rice vs wheat)
      3. Disease classifier (3-4 diseases + Healthy)
      4. Severity stage (wheat only)
      5. Live weather risk assessment
      6. Treatment recommendation

      Limitations

      • Rice staging not available
      • Heuristic — consult an agronomist
      • Best on single-leaf, plain backgrounds
